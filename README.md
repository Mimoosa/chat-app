## Overview
This project is a full‑stack real‑time chat application built by following a MERN stack tutorial.
It includes a React (Vite) frontend, an Express + MongoDB backend, real‑time messaging with Socket.io, and a production deployment on Render.

## Teck Srack
- React (Vite) – frontend UI
- Zustand + useContext – lightweight global state & auth context
- Socket.io – real‑time communication
- TailwindCSS + DaisyUI – styling & components
- Express + Node.js – backend API
- MongoDB – database
- JavaScript – full‑stack implementation
- Render – production hosting and deployment
